<Section pad="column" label="What it is" id="about">

**gwm** creates one isolated worktree per branch in a single command, following
the `<type>/#<issue>-<desc>` convention, and prepares each one through a
bootstrap described in `.gwm.toml`. One branch is one physical directory: its
own `target/`, its own dependencies, its own local config. Nothing is stashed,
nothing is rebuilt on every switch.

It is a single self-contained binary. Worktree operations run on vendored
libgit2, so there is no shell-out to parse and no `gwq` to install first.

</Section>

<Section pad="column" label="Install">

```bash
# Homebrew
brew install kbrdn1/tap/gwm

# Prebuilt archives, no Rust toolchain
cargo binstall gwm-cli

# From crates.io
cargo install gwm-cli
```

Bare `gwm` opens the list. Everything else is one key away: `/` filters, `2`
focuses the sidebar, `n` creates, `L` drops into lazygit, `O` opens the worktree
in your editor.

Every pane is documented in [the TUI guide](/tui/), from the keybindings to the
command palette and the theme presets.

<Section pad="column" label="What you get">

<FeatureRow n="01" title="One command per worktree">
  `gwm create feat 12 my-feature` opens the `feat/#12-my-feature` branch, its worktree, and runs the
  repo's bootstrap. `gwm remove` takes it all back down, with `--dry-run` if you want to look first.

  <Capture
    src={createBootstrap}
    alt="Terminal output: gwm init writes a .gwm.toml from the rust preset, then gwm create opens the feat/#1-health-check branch, its worktree, and prints the bootstrap report"
    cmd="gwm create feat 1 health-check --allow-bootstrap"
    tag="CLI"
    caption="From an empty repo to a bootstrapped worktree - and the bootstrap says exactly what it did, hook by hook."
  />
</FeatureRow>

<FeatureRow n="02" title="Bootstrap that belongs to the repo">
  `.gwm.toml` describes branch conventions, file copies, regex guards, no-symlink invariants and
  lifecycle hooks. Everyone who clones gets the same worktrees, and a TOFU trust ledger asks before
  running anything.

  <Capture
    src={trustLedger}
    alt="gwm printing the full bootstrap surface of an untrusted .gwm.toml - path, origin, hash, the copies and commands it would run - then asking to trust it"
    cmd="gwm create feat 4 stripe-gateway"
    tag="Trust"
    caption="An untrusted .gwm.toml shows its whole surface - every copy, every command - before a single one runs."
  />
</FeatureRow>

<FeatureRow n="03" title="The issue and the PR, in the worktree">
  A branch named `feat/#42-…` links itself to issue #42 with zero config, `gh` or `glab` fetches the
  live state, and the detected PR lands next to it - title, state, CI. It lives in git config, per
  branch, so it survives a move and is never committed.

  <Capture
    src={githubLinking}
    alt="The gwm sidebar showing an auto-linked issue and a gh-detected open pull request with its CI status"
    cmd="gwm status"
    tag="GitHub"
    caption="Issue auto-linked from the branch name, PR detected, CI running 8/9 - without leaving the list."
  />
</FeatureRow>

<FeatureRow n="04" title="A TUI when the CLI is not enough">
  Bare `gwm` opens a ratatui interface: filter, status sidebar, embedded lazygit and shell overlays,
  a command palette, and a keymap you can rebind live from the settings panel.

  <Capture
    src={sideBySide}
    alt="The gwm TUI in its side-by-side layout, the status sidebar on the left and the worktree list on the right"
    cmd="gwm  ›  Space"
    tag="Layout"
    caption="Space cycles the layout auto → side-by-side → stacked, v flips the sidebar left ↔ right."
  />
</FeatureRow>

<FeatureRow n="05" title="Built for scripts too">
  `--format=json` on `list`, `doctor` and `path` with frozen schemas, plus a JSON-RPC daemon with a
  subscribe stream. `gwm statusline` renders a one-line summary for tmux, starship or a zsh prompt.

  <Capture
    src={doctor}
    alt="gwm doctor output: eight checks, each passing, with the detail line under it"
    cmd="gwm doctor"
    tag="CLI"
    caption="Same checks in --format=json, with a frozen schema and an exit code you can branch on."
  />
</FeatureRow>

<FeatureRow n="06" title="Fleet chores across worktrees">
  `gwm exec -- cargo test` runs a command in every worktree with a per-worktree rollup, and `gwm
  clean` reports reclaimable build directories before deleting anything.
</FeatureRow>

</Section>
