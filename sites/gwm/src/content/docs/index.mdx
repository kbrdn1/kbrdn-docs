## Installation

<Tabs>
  <TabItem label="Homebrew">

```sh
brew tap kbrdn1/tap
brew install gwm
```

  </TabItem>
  <TabItem label="cargo-binstall">

```sh
cargo binstall gwm
```

  </TabItem>
  <TabItem label="Cargo (sources)">

```sh
git clone https://github.com/kbrdn1/gwm-cli.git
cd gwm-cli
cargo install --path .
```

  </TabItem>
  <TabItem label="Binaire précompilé">

```sh
# Télécharger l'archive depuis les GitHub Releases (avec son sidecar .sha256) :
# Linux x86_64/aarch64, macOS Intel/Apple Silicon, Windows x86_64.
# Déposer le binaire `gwm` sur le $PATH et le rendre exécutable.
```

  </TabItem>
  <TabItem label="Nix">

```sh
nix run github:kbrdn1/gwm-cli -- list
nix profile install github:kbrdn1/gwm-cli
```

  </TabItem>
</Tabs>
